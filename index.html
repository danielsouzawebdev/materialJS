JavaScript: a camada que reage.

Um material só sobre JavaScript, em três níveis. HTML dá a estrutura, CSS dá a aparência — é o JavaScript que faz a página responder a cliques, mudar sozinha, conversar com um servidor.

Onde o JavaScript roda

Diferente de HTML e CSS, JavaScript é uma linguagem de programação de verdade — com variáveis, funções, decisões. O lugar mais comum onde ele roda é dentro do próprio navegador, mas a mesma linguagem também roda em servidores (Node.js), aplicativos e mais.

Toda a prática deste material acontece no console do navegador — um lugar para rodar JavaScript e ver o resultado na hora, sem precisar configurar nada.

Console — DevTools
> let nome = "Ana";
> console.log("Olá, " + nome);
Olá, Ana
// pressione F12 e cole esse código na aba Console

Como usar este material

  • Para testar trechos curtos: abra qualquer página, pressione F12, vá na aba Console e cole o código.
  • Para os projetos maiores: um arquivo script.js separado, ligado ao HTML com <script src="script.js" defer></script> antes de fechar o <head>, ou diretamente antes de </body>.
  • Use a página de portfólio do material de HTML e os estilos do material de CSS como base para aplicar o comportamento deste material.
