JavaScript Intermediário

Pré-requisito: JavaScript Básico. Aqui o código sai do console e passa a controlar uma página de verdade.

1. Selecionar elementos do DOM

const titulo = document.querySelector("h1");
const primeiroItem = document.querySelector(".item");
const todosOsItens = document.querySelectorAll(".item");
const porId = document.getElementById("menu");
MétodoRetorna
querySelector(seletor)o primeiro elemento que casa com o seletor CSS, ou null
querySelectorAll(seletor)uma lista (NodeList) com todos os elementos que casam
getElementById(id)o elemento com aquele id, mais rápido mas menos flexível

querySelector aceita qualquer seletor CSS válido — "#id", ".classe", "ul li:first-child" — exatamente a mesma sintaxe do material de CSS.

2. Manipular o DOM

const titulo = document.querySelector("h1");

titulo.textContent = "Novo título";      // só texto, seguro contra HTML malicioso
titulo.innerHTML = "Novo <em>título</em>"; // interpreta HTML — cuidado com dados de usuário

titulo.style.color = "blue";
titulo.style.fontSize = "2rem";

titulo.classList.add("destaque");
titulo.classList.remove("oculto");
titulo.classList.toggle("ativo");         // adiciona se não tem, remove se já tem

titulo.setAttribute("data-status", "ok");
titulo.getAttribute("data-status");        // "ok"
innerHTML e segurança

Nunca jogue texto digitado por um usuário direto em innerHTML sem tratar — é a porta de entrada clássica para um ataque de injeção de código (XSS). Quando o conteúdo é só texto, prefira sempre textContent.

3. Eventos

const botao = document.querySelector("#meu-botao");

botao.addEventListener("click", () => {
  console.log("Botão clicado!");
});

botao.addEventListener("click", function (evento) {
  console.log(evento.target);       // o elemento que disparou o evento
  evento.preventDefault();           // cancela o comportamento padrão (em links/forms)
});

document.addEventListener("keydown", (evento) => {
  if (evento.key === "Enter") {
    console.log("Enter pressionado");
  }
});
EventoDispara quando
clicko elemento é clicado
submitum formulário é enviado
inputo valor de um campo muda, a cada tecla
keydown / keyupuma tecla é pressionada / solta
DOMContentLoadedo HTML terminou de carregar (em document)

4. Métodos de array

const numeros = [1, 2, 3, 4, 5];

const dobrados = numeros.map(n => n * 2);          // [2, 4, 6, 8, 10]
const pares = numeros.filter(n => n % 2 === 0);     // [2, 4]
const soma = numeros.reduce((total, n) => total + n, 0); // 15
const encontrado = numeros.find(n => n > 3);          // 4
const existe = numeros.some(n => n > 4);               // true
const todosPositivos = numeros.every(n => n > 0);        // true

numeros.forEach(n => console.log(n));

const ordenado = [3, 1, 2].sort();                       // [1, 2, 3]
MétodoFazRetorna
maptransforma cada itemarray novo, mesmo tamanho
filtermantém só os aprovadosarray novo, menor ou igual
reduceacumula tudo num valorum valor só
findpara no primeiro aprovadoo item, ou undefined
some / everytesta a lista inteiratrue/false
Hábito a desenvolver

Toda vez que a solução for "percorrer um array e fazer algo com cada item", pergunte primeiro: isso é um map, um filter ou um reduce? Esses três cobrem a maioria dos casos antes de precisar de um loop manual.

5. Objetos e desestruturação

const pessoa = {
  nome: "Ana",
  idade: 25,
  endereco: { cidade: "São Paulo", uf: "SP" },
  falar() {
    console.log(`${this.nome} está falando`);
  }
};

pessoa.nome;              // "Ana"
pessoa["nome"];            // "Ana" — mesma coisa, útil quando a chave é dinâmica
pessoa.falar();

// desestruturação — extrai propriedades direto em variáveis
const { nome, idade } = pessoa;
const { cidade } = pessoa.endereco;

// spread — copia propriedades para um objeto novo
const pessoaAtualizada = { ...pessoa, idade: 26 };

O spread (...pessoa) cria um objeto novo, copiando as propriedades — é assim que se atualiza um valor sem alterar o objeto original, um padrão comum ao trabalhar com estado em interfaces.

6. Formulários com JS

const form = document.querySelector("#cadastro");

form.addEventListener("submit", (evento) => {
  evento.preventDefault();   // impede o recarregamento padrão da página

  const nome = document.querySelector("#nome").value;
  const email = document.querySelector("#email").value;

  if (nome.trim() === "") {
    alert("Preencha o nome.");
    return;
  }

  console.log("Enviando:", { nome, email });
});

evento.preventDefault() é essencial aqui — sem ele, o formulário tentaria recarregar a página (comportamento padrão do HTML), e o JavaScript nunca teria a chance de processar os dados antes disso acontecer.

7. JSON e localStorage

const pessoa = { nome: "Ana", idade: 25 };

const texto = JSON.stringify(pessoa);   // objeto → texto: '{"nome":"Ana","idade":25}'
const devolta = JSON.parse(texto);       // texto → objeto de novo

// localStorage guarda dados no navegador, entre sessões
localStorage.setItem("usuario", JSON.stringify(pessoa));

const salvo = JSON.parse(localStorage.getItem("usuario"));
console.log(salvo.nome);   // "Ana"

localStorage.removeItem("usuario");

localStorage só guarda texto — por isso todo objeto precisa passar por JSON.stringify antes de salvar, e por JSON.parse ao recuperar. Os dados ficam salvos mesmo depois de fechar o navegador, até serem removidos explicitamente.

Projeto do nível: lista de tarefas com localStorage

  • Um input de texto e um botão "Adicionar"
  • Ao adicionar, a tarefa aparece numa lista (ul) na tela, usando createElement ou innerHTML
  • Cada tarefa tem um botão "Concluir" que risca o texto (classList.toggle com uma classe .concluida { text-decoration: line-through; })
  • Cada tarefa tem um botão "Remover"
  • A lista inteira é salva no localStorage a cada mudança, e recarregada automaticamente quando a página abre de novo
