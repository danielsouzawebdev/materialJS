JavaScript Básico

Oito módulos curtos — a gramática da linguagem. Teste cada exemplo no console do navegador (F12) antes de seguir para o próximo.

1. Onde o JS roda

<!-- no fim do body, depois de todo o HTML que o script usa -->
<script src="script.js" defer></script>
</body>
// script.js
console.log("O script carregou!");

console.log() é a ferramenta mais usada em todo este material — imprime um valor no console do navegador, sem aparecer nada na tela da página. É assim que se inspeciona o que o código está fazendo, passo a passo.

Pratique agora

Abra qualquer página (inclusive esta), pressione F12, clique na aba Console, digite console.log("oi") e pressione Enter.

2. Variáveis e tipos

let nome = "Ana";          // pode mudar depois
const PI = 3.14;            // não pode ser reatribuída
let idade = 25;              // number
let ativo = true;            // boolean
let nada = null;             // ausência intencional de valor
let indefinido;               // undefined — ainda não recebeu valor

console.log(typeof nome, typeof idade, typeof ativo);
// string number boolean
Palavra-chaveComportamento
constnão pode ser reatribuída — use por padrão
letpode mudar — use só quando o valor realmente for mudar
varforma antiga, com regras de escopo confusas — evite
null vs undefined

undefined é o que o JavaScript dá sozinho a algo que ainda não tem valor. null é um valor que você atribui de propósito para dizer "vazio por design". A diferença costuma confundir — na dúvida, prefira null quando for você quem está esvaziando algo intencionalmente.

3. Operadores

// aritméticos
10 + 3;   // 13
10 - 3;   // 7
10 * 3;   // 30
10 / 3;   // 3.333...
10 % 3;   // 1 (resto da divisão)

// comparação
5 == "5";    // true  — compara só o VALOR, converte tipo
5 === "5";   // false — compara valor E tipo
5 !== "5";   // true

// lógicos
true && false;   // AND — false
true || false;   // OR  — true
!true;            // NOT — false
Regra para a vida toda

Use sempre === e !==, nunca == ou !=. A versão com três sinais de igual não faz conversão de tipo escondida, o que evita bugs difíceis de rastrear como 0 == "" retornando true.

4. Strings

const nome = "Ana";
const sobrenome = 'Silva';

// template literals — crase, não aspas
const completo = `${nome} ${sobrenome}`;
console.log(`Olá, ${completo}! Você tem ${25 + 1} anos.`);

// métodos comuns
"  texto com espaço  ".trim();        // "texto com espaço"
"Ana".toUpperCase();                   // "ANA"
"ANA".toLowerCase();                   // "ana"
"javascript".includes("script");       // true
"a,b,c".split(",");                    // ["a", "b", "c"]
"Ana".length;                          // 3

Template literals (com crase `) permitem inserir variáveis direto no texto com ${}, sem precisar concatenar com + — mais fácil de ler, principalmente em strings longas.

5. Condicionais

let idade = 17;

if (idade >= 18) {
  console.log("Maior de idade");
} else if (idade >= 13) {
  console.log("Adolescente");
} else {
  console.log("Criança");
}

// switch — bom quando há muitas comparações do MESMO valor
switch (diaDaSemana) {
  case "segunda":
    console.log("Começo de semana");
    break;
  case "sexta":
    console.log("Quase lá");
    break;
  default:
    console.log("Dia comum");
}

// ternário — um if/else curto, numa expressão só
const status = idade >= 18 ? "liberado" : "bloqueado";

6. Loops

for (let i = 0; i < 5; i++) {
  console.log("Volta número", i);
}

let contador = 0;
while (contador < 3) {
  console.log(contador);
  contador++;
}

const frutas = ["maçã", "banana", "uva"];
for (const fruta of frutas) {
  console.log(fruta);
}
LoopQuando usar
forquando se sabe o número de voltas, ou precisa do índice
whilequando a condição de parada depende de algo que muda durante o loop
for...ofpara percorrer os itens de um array diretamente, sem lidar com índice
Exercício

Escreva um for que imprime os números de 1 a 20, mas substitui múltiplos de 3 por "Fizz", múltiplos de 5 por "Buzz", e múltiplos de ambos por "FizzBuzz" — um clássico para treinar condicional dentro de loop.

7. Funções

function saudacao(nome) {
  return "Olá, " + nome + "!";
}

// arrow function — forma mais curta, comum em código moderno
const saudacao2 = (nome) => "Olá, " + nome + "!";

// parâmetro com valor padrão
function multiplicar(a, b = 2) {
  return a * b;
}

console.log(saudacao("Ana"));
console.log(multiplicar(5));      // 10 (usa o padrão b=2)
console.log(multiplicar(5, 3));   // 15

Uma função que não tem return explícito devolve undefined automaticamente. Isso costuma ser a causa de bugs do tipo "por que minha variável virou undefined" — confira sempre se a função realmente retorna algo.

8. Arrays básico

const numeros = [10, 20, 30];

numeros[0];          // 10 — índice começa em zero
numeros.length;       // 3

numeros.push(40);     // adiciona no final → [10, 20, 30, 40]
numeros.pop();         // remove o último → [10, 20, 30]
numeros.unshift(5);    // adiciona no início → [5, 10, 20, 30]
numeros.shift();        // remove o primeiro → [10, 20, 30]

numeros.indexOf(20);    // 1
numeros.includes(99);   // false
Exercício

Crie um array com os nomes de 5 colegas. Use um for...of para imprimir cada nome precedido de "Olá, ", e depois use .push() para adicionar mais um nome ao final.

Projeto do nível: calculadora de idade

Escreva uma função calcularFaixaEtaria(anoNascimento) que:

  • Calcula a idade com base no ano atual (use new Date().getFullYear())
  • Retorna "criança" para menores de 13, "adolescente" até 17, "adulto" no resto
  • Usa console.log para mostrar uma frase completa, como "Com 25 anos, você é considerado adulto."
  • Lida com um ano de nascimento inválido (maior que o ano atual) imprimindo uma mensagem de erro amigável, em vez de um resultado sem sentido
